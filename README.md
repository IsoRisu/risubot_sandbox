## Modern Snake Game

An immersive, feature-rich modern Snake game built for the browser using modern ES6 modules. Open `index.html` to play.
>

### Features & Controls
- **Modern UI Layout**: Polished HUD with live score tracking, high score persistence (`localStorage`), smooth canvas animations, particle bursts, and active power-up status indicators.
- **Controls**:
  - **Arrow Keys / WASD**: Steer the snake.
  - **Pause (`P`)**: Pause or resume your game anytime.
  - **Restart (`R` or Space)**: Instantly reset and restart your game session.
- **Progression & Customization**:
  - Earn coins by playing and achieving milestones.
  - Unlock and equip unique Snake Skins (Classic Green, Neon Cyber, Golden Serpent, Cyberpunk Riot, Rainbow Prism).
  - Track progression across multiple Achievements with coin rewards.
- **Special Food Types & Power-ups**:
  - 🟥 **Normal Food (Red)**: Standard growth and `+10` points.
  - 🟨 **Bonus Food (Yellow)**: High-value nourishment worth `+30` points.
  - 🟦 **Slow-Down Effect (Blue)**: Temporarily slows down snake speed (`+15` points).
  - 🟪 **Speed-Up Effect (Purple)**: Temporarily increases snake speed (`+20` points).
  - 🟩 **Multiplier, Ghost, Magnet & Freeze**: Exciting tactical power-ups for high scoring.
