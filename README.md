## Modern Snake Game

An immersive, feature-rich modern Snake game built for the browser! Open `index.html` to play.

### Features & Controls
- **Modern UI Layout**: Polished HUD with live score tracking, high score persistence (`localStorage`), smooth canvas animations, and active power-up status indicators.
- **Controls**:
  - **Arrow Keys**: Steer the snake (Left, Up, Right, Down).
  - **Pause (`P`)**: Pause or resume your game anytime.
  - **Restart (`R` or Space)**: Instantly reset and restart your game session.
- **Gameplay Mechanics & Speed Variations**:
  - Progressive speed scaling as your score increases to keep the challenge exciting.
  - Precise grid collision detection against walls and the snake's own tail.
- **Special Food Types & Power-ups**:
  - 🟥 **Normal Food (Red)**: Standard growth and `+10` points.
  - 🟨 **Bonus Food (Yellow)**: High-value nourishment worth `+30` points.
  - 🟦 **Slow-Down Effect (Blue)**: Temporarily slows down snake speed for easier maneuvering (`+15` points).
  - 🟪 **Speed-Up Effect (Purple)**: High-risk thrill that temporarily increases snake speed (`+20` points).
